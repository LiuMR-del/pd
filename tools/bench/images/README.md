# 测试图集（阶段 0）

- 生成日期：2026-10-29
- 数量：22 张 PNG，分 7 类：cartoon 4、portrait 3、pet 3、landscape 3、text 3、pixel 3、ai 3
- 来源：YouTube 视频封面图。用 yt-dlp（2026.10.26，源码 commit `f264a6cb`）加「知识共享」搜索筛选找候选，再逐个打开视频页核实许可证为 **Creative Commons Attribution（CC BY）**，然后人工挑选。
- 每张图的标题、作者频道、原链接、许可证见 `manifest.csv`。获取脚本在 `../fetch/`。

## 使用约束
1. CC BY 要求署名：对外展示或分发这些图时，要按 `manifest.csv` 注明作者和来源链接。
2. **不提交到公开仓库**：`tools/bench/images/*.png` 加进 `.gitignore`，只提交 `manifest.csv` 和本说明。理由：人像类涉及真人肖像，部分封面里含第三方商标或文字。
3. 只用于算法评测，不用于产品内的素材或宣传。

## 已知局限
- 封面图最大为 1280×720，经过 JPEG 压缩，有压缩块噪点。这对拼豆转换反而是贴近真实的输入。
- 很多封面图带标题大字，这类图同时可以测文字和描线的效果。
- ai 类是否为 AI 生成是凭画风判断的，没有确认。`ai_01`、`ai_02` 原本是竖屏视频，已裁出中间的 9:16 区域，尺寸 405×720。
- 剔除了：疑似搬运的版权动画（DAN DA DAN、Puppy Dog Pals）、商业游戏画面（Castlevania、Super C）、酷似真人明星的 AI 图。
- 还缺「真实像素点阵原图」（无缩放的小尺寸像素图）。建议阶段 0 用程序生成合成图补上，或者由用户补充。
