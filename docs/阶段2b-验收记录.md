# 阶段 2b 验收记录：小程序账号与云同步

> 计划见 `docs/阶段2b-计划.md`。开发者工具 + 本机后端（127.0.0.1:3100）+ 本机 MySQL；真实微信登录（测试号 AppID `wxde40fa09302aacf0`，AppSecret 在 `apps/server/.env`，不入库）。

## 2b-1 后端：绑定微信、给微信账号设置网页登录（2026-11-07）

- `POST /api/me/wx-bind { code }`：把这个微信绑到当前登录的账号，以后小程序一键登录就进这个账号。这个微信如果已经有一个**空的**微信账号（没作品、没密码），删掉那个空账号再绑；如果那个账号里有作品或设了密码，拒绝（`wx_in_use`），不自动合并。当前账号已绑别的微信时拒绝（`wx_already_bound`）。
- `PUT /api/me/credentials { username, password }`：只给没有用户名和密码的账号（微信建的）设置一次（`credentials_exist`），用户名被占用时 `username_taken`。
- 接口测试新增 5 个，server 共 44 个通过。

## 2b-2 共享同步引擎（2026-11-07）

`packages/app-shared/src/sync.ts`，和平台无关，规则照搬网页 `apps/web/src/cloud.ts`：先发本机删除（带版本号，别处改过就不删并重新下载）→ 拉取变化（游标往前多取 10 秒）→ 上传有修改的作品（带 baseRevision）。冲突时本机这份另存「（冲突副本）」，别处删除但本机改过另存「（已在别处删除）」，任何一方都不被覆盖。原图先下载到临时文件，再检查本机有没有新修改、再写入，避免下载期间的修改被覆盖。单测 14 个（假服务端 + 假本地存储，两台「设备」共用一个服务端）。

## 2b-3 / 2b-4 小程序接入（2026-11-07）

做了什么：
- 「我的」页：勾选同意协议后「微信一键登录」，或「用网页账号登录」（用户名 + 密码）；登录后显示昵称、同步状态、「立即同步」；没绑微信的可「绑定」，微信建的账号可「设置网页登录」（用户名 + 密码）；「退出登录」。用户协议、隐私政策页面（草案，按小程序改写：微信登录只保存 openid，不取昵称头像手机号）。
- 首页加「登录 / 我的」入口。
- 作品归属：登录时做的作品属于这个账号；没登录时做的作品留在手机上，登录时询问「存到账号吗」。退出登录后账号的作品在手机上隐藏（不删），再登录出现。
- 同步：保存后 2 秒、打开小程序 / 回到前台、进「我的作品」、联网时自动同步；「我的作品」每个作品显示「已同步 / 待同步 / 仅在手机上」。删除作品时云端一起删除。
- 编辑页和同步的配合：同步前先把编辑页没存的修改写盘；编辑中的作品被另存为冲突副本时，编辑页直接切到副本继续编辑（修改不丢）；作品在别处更新时自动载入新版本；在别处删除时提示并返回。保存时带着「打开时的云端版本号」，如果期间已经下载了更新的版本，这次保存另存为冲突副本而不是覆盖。
- 原图：上传前不是 PNG / JPG / WebP 或大于 7.5MB 的先压缩成 JPG（服务器上限 8MB）；下载用带令牌的 `downloadFile`。
- 接口地址默认 `http://127.0.0.1:3100/api`，可用环境变量 `VITE_API_BASE` 改（真机测试时填电脑的局域网地址）。
- 新增单测：接口客户端 8 个（令牌刷新、并发只刷新一次、会话失效退出、离线、上传字节）、作品存储 8 个（归属、隐藏、转存、上传记账、下载存储、冲突副本、副本归属、删除）。小程序共 58 个。

**提交前审查（独立代理）**：结论「没有会丢数据的阻断问题」。按建议修了：
- 改昵称用的 PATCH 在 `wx.request` 里不支持（真机会失败）→ 后端加 `PUT /api/me`，小程序改用 PUT；自动化新增「改昵称」一项。
- 启动时要等 `/me` 返回才知道账号，这期间新建的作品没有归属、永远不上传；离线启动时「我的」显示未登录 → 记住上次的账号，启动时立刻使用，联网 / 回到前台后再向服务器确认。
- 原图上传只有 20 秒超时、压缩后没再查大小 → 上传单独 90 秒；压缩后仍超 8MB 时只这一个作品报错，不拖住其他作品。
- 一张原图下载失败（不是离线）会卡住整个同步 → 保留本地原图继续同步；上传时不再因为本机没有原图就把云端的原图清掉（新增单测）。
- 编辑页有没生成的设置 / 裁剪 / 文字时，云端新版本不再直接覆盖页面，之后的保存自动另存为冲突副本。
- 冲突副本、「修改前」备份沿用原作品的账号（被迫退出登录后产生的副本不会被别的账号领走；新增单测）。
- 作品第一次上传还没完成就删除，同步会把它「复活」→ 没有版本号的也发删除请求。
- 未修（记为已知）：极少数时序下，冲突副本配到的原图可能已被云端新图替换。

另外：后端监听地址可用环境变量 `HOST` 改（默认仍是只监听本机），为真机测试准备。
