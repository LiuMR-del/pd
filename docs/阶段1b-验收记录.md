**过程中发现并修复**：
- **开发者工具把代码转成 ES5 后，`instanceof MakerError` / `instanceof CancelledError` 判断失效**（继承 Error 的类丢了原型），空内容的正常情况被当成错误显示 → 两个错误类在构造时恢复原型，并加单测。
