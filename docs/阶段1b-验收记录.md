## 1b-2 选图 → 裁剪 → 参数 → 生成 → 画布显示（2026-11-05）

**结论：通过（开发者工具模拟器，自动化脚本 14 项全过 + 截图人工核对）。**

做了什么：
- 首页「选图片生成」：相册或拍照（`chooseMedia`），进入编辑页。
- 编辑页：画布先显示原图；「裁剪」拖动框移动、拖四角调整大小，框外变暗；「全图 / 取消 / 完成」。
- 设置面板（与网页同一套设置，已抽到共享包 `@pd/app-shared`）：风格、尺寸（省豆 / 均衡 / 细节 / 自定义滑块）、品牌、色号范围、去掉背景、细线保护；上次用的设置会记住。
- 生成在 Worker 里跑，可取消；结果画在画布上（网格线、格子够大时显示色号），可在「图纸 / 原图」间切换，显示「格数 · 色数 · 颗数」；改了设置或裁剪后按钮变成「按新设置重新生成」；结果为空时给中文提示。
- 解码：图片先缩到长边 1024 像素再取像素（图纸最长 200 格，足够；也控制手机内存和 Worker 消息大小）。预览和解码走同一种画布图片加载，保证裁剪框和实际像素对得上。

**过程中发现并修复**：
- 裁剪时「全图 / 取消 / 完成」三个按钮被左边提示文字挤成竖排、结果摘要折成两行 → 按钮不缩、不换行，摘要字号调小；复测正常（见截图 2、3）。
- 新增的设置面板组件在开发者工具里报「Component is not found」：组件目录是工具启动后才生成的，热重载没识别 → 用命令行关闭再打开项目后正常（不是代码问题）。
- 自动化脚本里第一次「改设置」没生效：上次用的「照片」风格被记住了，脚本又点了同一个 → 改脚本（选未选中的那个），是预期行为。

**未验证 / 限制**：
- 模拟器里「选图」是电脑上的文件对话框；真机的相册 / 拍照、**手机拍的竖图（EXIF 方向）是否方向正确**、大图解码耗时，留到 1b-6 真机验收。
- 「取消生成」按钮：生成太快（约 0.3 秒）来不及在界面上点，取消逻辑由单测覆盖（`generator.test.ts`）。
