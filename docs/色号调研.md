# MARD 色号调研

> 2026-11-03 · 起因：真实用户看了生成的图纸，反馈「色号不对」。
> 方法：只看公开网页，人工核对；没有登录任何平台，没有批量爬取电商网站，没有访问豆格、今天拼豆了吗的接口。
> 网页源码只下载阅读（放在会话临时目录），没有执行，也没有放进仓库。

## 1. 结论

我们的 MARD 色卡数据有三处错误，任何一处都会让用户觉得「色号不对」：

| # | 问题 | 现状 | 实际 | 影响 |
|---|---|---|---|---|
| 1 | **色号写法** | 291 个色号里有 110 个带前导零，例如 `A01`、`H07`、`T01` | 官方淘宝店规格、实物豆袋标签、各工具都写作 `A1`、`H7`（见 2.1 节） | 用户在豆袋上找不到 `A01` |
| 2 | **套装档位** | 24~221 色档是我们用算法挑出来的（`synthetic: true`） | MARD 实际在卖 24 / 48 / 72 / 96 / 120 / 144 / 221 色套装，每档色号固定，且层层包含 | 我们的 24 色档只有 3 个色号在真实 24 色套装里；72 色档对上 17 个，221 色档对上 169 个。图纸会出现用户套装里没有的色号 |
| 3 | **默认色板** | 网页默认用「全部 291 色」 | 普通套装最多 221 色（A~H、M 共 9 个系列）；另外 70 色是珠光、果冻、透明、夜光等特殊系列（P/Q/R/T/Y/Z） | 图纸里会混进用户没有的特殊豆 |

另外，色值也有偏差：283 个共有色号里，与下述来源相比有 73 个 ΔE76 > 5，最大的约 47（Q2、Q5 等特殊系列）。perler-beads 里特殊系列的写法是 `ZG1~ZG8`，其他来源都写作 `Z1~Z8`。

## 2. 来源与可信度

| 来源 | 内容 | 可信度 |
|---|---|---|
| [MARD拼豆助手](https://pixto.mardtoys.cn/)（`mardtoys.cn` 域名，网页应用） | 221 色色值表；24~144 色各套装色号清单；套装选项 24/48/72/96/120/144/221/280 | **较高**：域名带 MARD 品牌名，但没能在公开资料里核实运营方（淘宝店铺页需登录） |
| [mardbeads.com 色卡](https://mardbeads.com/mard-beads-color-chart) | 291 个色号及其所属套装（24~291），屏幕色值 | 中：第三方站点，但套装清单与上一个来源**逐个色号完全一致** |
| [GitHub HansBug/pindou-color-data](https://github.com/HansBug/pindou-color-data) | MARD 221 / 291，以及优肯、COCO、漫漫、盼盼、咪小窝等品牌色卡（JSON / XLSX / PDF） | 中：整理自多个公开工具，注明 MARD 221 有两个来源、77 个色值不一致 |
| [pindou.online](https://www.pindou.online/colors)、[豆豆工坊](https://www.doudougongfang.com/kb/beads/mard-palette)、[mypindou](https://mypindou.com/colors/mard/)、[Bitbead](https://www.bitbead.app/en/colors/mard) 等 | 221 / 291 色号与色值 | 中：都写作 `A1` 格式；色值彼此有小差异 |
| perler-beads（我们现在的数据） | 291 色、`A01` 格式、5 个品牌按 MARD 色值映射 | 低：写法与实物不一致，非 MARD 品牌不是实测 |

各方一致的部分：
- 221 色 = A1–A26、B1–B32、C1–C29、D1–D26、E1–E24、F1–F25、G1–G21、H1–H23、M1–M15。
- 291 色 = 221 色 + P、Q、R、T、Y、Z 等特殊系列（另有 280 色档）。
- 色值都是屏幕近似值，实物受批次、光线影响，各站点都提醒以实物为准。

## 4. 建议的修改方案（待用户确认）

1. **色号写法**：MARD 色号去掉前导零（`A01` → `A1`），特殊系列 `ZG` → `Z`。改动在 `packages/palettes/scripts/build.ts`，图纸和草稿里只存色板下标，不受影响。
2. **套装档位**：用第 3 节的真实清单替换算法生成的 24~221 色档，去掉不存在的 168 色档，`synthetic` 标记改为来源说明。
3. **默认色板**：网页默认改为「MARD 221 色」；色数档下拉框写成用户熟悉的「24 色套装」「72 色套装」……「291 色（含珠光、透明等特殊豆）」。
4. **色值**：以 MARD 拼豆助手的 221 色色值为主（与 mardbeads.com 有 63 个小差异，需要选定一个）；特殊系列暂用 perler-beads 色值并标注「未核实」。色值的许可：这些网站没有声明开放许可，色号清单属于事实可以引用；色值表是否能直接收录进 AGPL 仓库，需要你确认，或改用注明许可的 GitHub 数据集（pindou-color-data，许可证待查）。
5. **其他 4 个品牌**（COCO、漫漫、盼盼、咪小窝）：本次没有调研。pindou-color-data 有它们独立的色卡（含无法辨认的色号），建议作为下一步。
6. 改完后重跑单测和 bench，在算法报告里记录色板变化对指标的影响。

## 4.1 实施结果（2026-11-03，用户确认：由 Claude 修改；色值不收进仓库）

- 色号写法：MARD 色号去掉前导零（`scripts/mard.ts` 的 `normalizeMardCode`）；特殊系列 `ZG1~ZG8` 暂不改名（各来源写法不一，未核实）。
- 套装档位：改为真实套装 24/48/72/96/120/144/221 + 全部 291；删除不存在的 168 档。套装清单写在 `packages/palettes/data/mard-kits.json`（只有色号，属于事实信息，注明来源）。
- 色值：`pnpm palettes:sync` 从 MARD拼豆助手下载 221 色色值到 `packages/palettes/data/local/mard-hex.json`（不进 git），下载结果要通过色号完整性校验才会写入；`data/palettes.json` 改为安装依赖时自动生成，也不进 git。没下载时退回 perler-beads 色值。本机下载后 85 个颜色被替换，原值保留在 `vendorHex` 字段。
- H2（白）在 MARD 数据里是 `#FFFFFF`，与 T1（透明豆）的 perler-beads 值相同；匹配时编号小的 H2 优先，纯白不会被配成透明豆。
- 网页默认色板改为 MARD 221 色套装；下拉框写作「72 色套装」等，291 色注明含特殊豆。旧的本机设置不再沿用。
- 已保存的旧作品里仍是旧写法（如 `A01`），重新生成即可更新。
