## 2. 工程结构

```
apps/miniapp/                      uni-app Vue3 + TS，只编 mp-weixin
  src/pages/index/                 首页：选图 / 文字 / 二维码入口 + 最近作品
  src/pages/editor/                设置 + 生成 + 编辑 + 用量 + 导出（单页，底部面板切换）
  src/pages/works/                 我的作品
  src/lib/                         平台适配：选图解码、Worker、文件存储、导出存相册、字形光栅化
  workers/generate.ts              Worker 源码，esbuild 打包成单文件 ES2015 → 输出目录 workers/
```

- **依赖版本**：`@dcloudio/*` 固定为 `3.0.0-5030420261029002`（vue3 标签，2026-10-30 发布，已过 pnpm 新版本冷却期）；它要求 vite 5.2.8，只装在 apps/miniapp，不影响网页的 vite 8。类型检查沿用网页的 TypeScript 5.9.3 + vue-tsc。
- **Worker**：uni-app 不打包小程序 Worker，所以用 esbuild 单独把 `pattern-core` 打成一个 ES2015 文件放进 `workers/`，`manifest.json` 里配置 `workers`。小程序 Worker 的消息只保证普通对象可传，像素和格子数组按普通数组 / base64 传输（实现时在开发者工具确认 ArrayBuffer 是否可直接传，可以就用）。
- **存储**：作品存成文件（`wx.env.USER_DATA_PATH/works/<id>.json` + 缩略图 + 原图 jpg），索引放 `wx.setStorageSync`（单键 ≤ 1MB，总量 ≤ 10MB，只放摘要）。草稿格式与网页相同（`@pd/editor-core` 的 PatternDraftV1），阶段 2 上云时两端通用。
- **画布**：`<canvas type="2d">` + `@pd/render`（已按标准 Canvas 2D 子集写，注释里已考虑小程序）；导出用 `wx.createOffscreenCanvas` 分块绘制 → `wx.canvasToTempFilePath` → `wx.saveImageToPhotosAlbum`。单块边长 ≤ 4096。
- **隐私**：保存相册需要在小程序后台填写《用户隐私保护指引》（声明「相册（仅写入）」）；开发阶段用测试号 / 游客 AppID 不受影响。
